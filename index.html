What is the 8-puzzle?

The 8-puzzle is a sliding tile puzzle played on a 3×3 grid holding eight numbered tiles and one blank space. Any tile horizontally or vertically adjacent to the blank can slide into it — that single move rule is the only action available at every state.

Starting from a scrambled arrangement, the goal is to reach a specified target arrangement using the fewest possible slides. Framed as a search problem: each arrangement of the board is a state, each legal slide is an action connecting two states, and solving the puzzle means finding a path through this state space from the initial state to the goal state.

Why it matters for search algorithms

The 8-puzzle has a state space of 9!/2 = 181,440 reachable configurations — small enough to search exhaustively, yet large enough to expose the real difference between blind and heuristic-guided search. It's a standard textbook benchmark for comparing uninformed strategies (BFS, DFS, DLS, IDDFS, UCS) against informed strategies (Greedy Best-First, A*) that use a heuristic function to estimate distance to the goal.

This build: A* Search

The algorithm assigned for this submission is A* Search. A* expands the node with the lowest evaluation function f(n) = g(n) + h(n), where g(n) is the exact cost from the start and h(n) is a heuristic estimate of the remaining cost to the goal. The Solver page implements it from scratch with a binary-heap frontier and two selectable heuristics — Misplaced Tiles and Manhattan Distance — and lets you step through every expansion.
